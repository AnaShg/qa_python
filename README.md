# Sprint 4 — Тестирование класса BooksCollector

## Описание проекта

В проекте реализованы автотесты для класса BooksCollector.
Тестирование выполнено с использованием библиотеки pytest.

Цель работы — проверить корректность логики добавления книг,
назначения жанров, работы с избранным и возрастными ограничениями.

## Реализованные тесты

### 1. Добавление книг
- Проверка успешного добавления книги
- Проверка, что книга не добавляется повторно
- Проверка ограничения длины названия
- Проверка добавления нескольких книг

### 2. Работа с жанрами
- Проверка установки жанра книге
- Проверка невозможности установить несуществующий жанр
- Проверка получения жанра книги
- Проверка получения списка книг по жанру

### 3. Избранное
- Проверка добавления книги в избранное
- Проверка удаления книги из избранного
- Проверка получения списка избранных книг

### 4. Возрастной рейтинг
- Проверка фильтрации книг по возрастному ограничению
- Проверка, что книги 18+ не отображаются в детском списке

## Используемые технологии

- Python 3
- pytest

## Как запустить тесты

В терминале выполнить команду:

pytest -v tests.py
